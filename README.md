# BENTO
## 🌐 Personal Link Website 🔗✨


![](example.png)

A super simple, clean, and elegant single-page website to share all your personal links (GitHub, Facebook, LinkedIn, and more) in one stylish place! 📄💼📱

---

## 📋 Installation and Setup 🛠️🚀

📦 **Copy files to your project folder:**
- `index.html` — page markup and core structure
- `style.css` — beautiful styles and layouts
- `image.png` — background / avatar

🌐 **Open** `index.html` **in your favorite browser to see it live!** 💻🔥

---

## 🛠️ Usage & Customization ✏️🎨

### 👤 Editing Main Information
Simply open the `index.html` file in a text editor and replace the default text, links, and profile image with your own awesome content! 😎✍️

### 🔗 Adding New Links
Want to add more social media? Just copy and paste this code block inside your HTML, substituting your own URLs and titles: 👨‍💻👇

```html
<a class="main__a" href="https://github.com/yourname" target="_blank">🐙 GitHub</a>
<a class="main__a" href="https://linkedin.com/in/yourname" target="_blank">💼 LinkedIn</a>
```
