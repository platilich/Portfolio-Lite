# Personal Link Website

A simple single-page website for sharing personal links (GitHub, Facebook, etc.).

## 📋 Installation and Setup

1. **Copy files** to your project folder:
   - `index.html` — page markup
   - `style.css` — styles
   - `image.png` — background (optional, example only)

2. **Open** `index.html` in your browser


## 🛠 Usage

### Editing Main Information

Edit the text, links, and image in the `index.html` file with your own content.

### Adding New Links

Copy and paste this block, substituting your own values:

```html
<a class="main__a" href="https://github.com/yourname" target="_blank">GitHub</a>
<a class="main__a" href="https://facebook.com/yourname" target="_blank">Facebook</a>
<a class="main__a" href="https://linkedin.com/in/yourname" target="_blank">LinkedIn</a>
```
